# 片羽 Typora 主题

一套面向长文写作、文字整理和持续创作的中西文 Markdown 排版主题。

## 包含主题

- 青瓷灰：清冷、克制，适合长文与日常写作
- 烟岚紫：安静、柔和，适合随笔与叙事
- 雨霁蓝：清透、理性，适合研究与结构化文档
- 本色：深色模式，适合专注写作

## 安装

在 Typora 中选择“偏好设置 → 外观 → 打开主题文件夹”，将以下内容复制进去：

1. `青瓷灰.css`
2. `烟岚紫.css`
3. `雨霁蓝.css`
4. `本色.css`
5. `pianyu-typora-themes/` 文件夹

重启 Typora 后，在主题菜单中选择片羽主题。四个主题共用 `pianyu-typora-themes/base.css`、字体和许可证文件，不能只复制 `.css` 文件。

字体许可证与来源见 [`pianyu-typora-themes/licenses/`](pianyu-typora-themes/licenses/)。完整设计说明见 [`片羽Typora主题展示与设计说明.md`](片羽Typora主题展示与设计说明.md)。
